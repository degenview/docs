# Script Manager

The Script Manager is where you write, organize, and run Pine Script. It's a library of
`.pine` files, each with a code editor, diagnostics, and a live preview chart.

## Writing a script

Open the Script Manager and create a new `.pine` file. The editor re-runs the script on the
preview chart **as you type**, so you see changes immediately.

## Diagnostics

Mistakes are surfaced as diagnostics right in the editor — syntax errors, type mismatches, and
similar problems — so you can fix them before running the script on a real chart.

## Organizing your library

Scripts are stored as `.pine` files you can create, rename, and delete. The library is local
to your machine.

## Running on a chart

Once a script is ready, apply it to a chart. The script's plots, shapes, backgrounds, and
candle colors render directly on that chart.

## Example scripts

DegenView ships with example scripts you can open and tweak. They're a good way to learn the
shape of a working script and see what the engine supports.
