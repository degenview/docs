# Charts

Charts are drawn by DegenView itself — no third-party chart library is involved.

## Chart types

Two chart types are available:

- **Candlesticks (OHLC)** — hand-drawn candles showing open, high, low, and close.
- **Line** — a line series following price.

Switch between them from the chart's type menu.

## What's on a chart

Every chart includes:

- A time axis and a price axis that adapts to the symbol's precision.
- A current-price overlay.
- A price-change readout so you can see the move at a glance.
- The source logo, so you always know which feed you're looking at.

## Scroll and zoom

Use the scroll wheel to zoom in and out across timeframes. Zoom is per-chart, so one chart
can be zoomed while its neighbors stay put.

## Price zoom

Drag the chart's Y-axis (the price axis) to adjust its vertical scale. This rescales price
without changing the time range.

## Crosshair

The crosshair is a synchronized vertical inspection line. Hover over one chart and the same
time position is highlighted across **every chart in that tab**, making it easy to compare
how different symbols moved at the same moment.
