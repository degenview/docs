# Indicators

Indicators overlay extra analysis onto a chart. Add them from the chart's indicator strip,
which sits below or beside the chart.

## Built-in indicators

- **Volume** — traded volume over time.
- **RSI** — the Relative Strength Index, a momentum oscillator.
- **EMA** — an exponential moving average with a configurable period.
- **Bollinger Bands** — a moving-average band showing volatility.
- **Supertrend** — a trend-following overlay that marks flips in direction.

## Configuring an indicator

Indicators with settings, like EMA, can be configured from the indicator strip. Change a
setting and the chart re-renders immediately.

## Removing indicators

Remove an indicator from the same strip you added it from.

## Indicators and Pine Script

Pine Script can draw its own plots, shapes, backgrounds, and candle colors on top of a chart.
Those render alongside the built-in indicators. See
[Pine Script](/pine/overview) for details.
