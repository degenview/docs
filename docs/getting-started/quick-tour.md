# A quick tour

Ten minutes from an empty window to a saved layout with an alert.

## 1. Add a chart

Open a new tab with `⌘T` (Ctrl+T on Windows and Linux), click the search box, type a symbol and pick a result. Or use **Add Chart** at the top right.

![The empty tab page with a search box and suggestions](/images/getting-started/empty-tab.png)

Add a few more charts. Each tab holds a grid of charts that share one timeframe. See [Adding charts](/markets/adding-charts).

## 2. Pick a timeframe and chart type

Use **1H, 1D, 1W, 1M, 3M, 1Y** at the top left to change the candle size for every chart in the tab. Use the chart-type button in a chart's header to switch between candles, bars, lines, Heikin Ashi, Renko and more. See [Chart types](/charts/chart-types).

## 3. Add indicators

Click the **+** next to a chart's title to add Volume, RSI, EMA, Bollinger Bands or Trend Flips. See [Indicators](/charts/indicators).

## 4. Draw on the chart

The strip on the left holds the drawing tools. Pick a tool, then click or drag on the chart. Click a drawing to change its colour, lock it or delete it. See [Drawing basics](/drawings/overview).

## 5. Keep a watchlist

Open the watchlist with the button at the top right, add symbols and click one to open it. See [Watchlists](/markets/watchlists).

![Four charts with a watchlist on the right](/images/markets/watchlist.png)

## 6. Set an alert

Click the bell in a chart's header, choose a price and press **Create Alert**. See [Price alerts](/alerts/price-alerts).

## 7. Save your layout

Open the layout menu at the top right, choose **Save layout** and give it a name. The name appears in the tab, and the layout is there next time you open DegenView. See [Layouts](/workspace/layouts).
