# Keyboard shortcuts

Every shortcut in DegenView in one place. On macOS the main key is ⌘. On Windows and Linux it is Ctrl, and Alt takes the place of ⌥ (Option).

Shortcuts that act on a chart use the focused chart, and are ignored while you type in a text field. Shortcuts also show in the menus next to the action. On a Mac, function keys may need Fn held.

## Tabs, layouts and Settings

| Action | macOS | Windows and Linux |
|---|---|---|
| New tab | ⌘T | Ctrl+T |
| Close tab | ⌘W | Ctrl+W |
| Next tab | ⌃Tab | Ctrl+Tab |
| Previous tab | ⌃⇧Tab | Ctrl+Shift+Tab |
| Open Settings | ⌘, | Ctrl+, |
| Save the layout (or the script in Pine Studio) | ⌘S | Ctrl+S |
| Undo | ⌘Z | Ctrl+Z |
| Redo | ⇧⌘Z | Ctrl+Y or Ctrl+Shift+Z |

## Charts and drawings

| Action | macOS | Windows and Linux |
|---|---|---|
| Trend line | ⌥T | Alt+T |
| Horizontal line | ⌥H | Alt+H |
| Horizontal ray | ⌥J | Alt+J |
| Vertical line | ⌥V | Alt+V |
| Crossline | ⌥C | Alt+C |
| Fib retracement | ⌥F | Alt+F |
| Hide or show all drawings | ⌃⌥H | Ctrl+Alt+H |
| Copy selected drawings | ⌘C | Ctrl+C |
| Paste drawings | ⌘V | Ctrl+V |
| Duplicate selected drawings | ⌘D | Ctrl+D |
| Delete selected drawings | Delete or Backspace | Delete or Backspace |
| Abandon a drawing, or deselect | Esc | Esc |
| Percent price scale (press again to go back) | ⌥P | Alt+P |
| Logarithmic price scale (press again to go back) | ⌥L | Alt+L |
| Save chart picture | ⌥⌘S | Ctrl+Alt+S |
| Copy chart picture | ⇧⌘S | Ctrl+Shift+S |
| Copy chart picture link | ⌥S | Alt+S |

Charts have no keyboard shortcuts for panning or zooming. See [Charts and navigation](/charts/charts).

## Replay

| Action | macOS | Windows and Linux |
|---|---|---|
| Step back, step forward | Shift+← and Shift+→ | Shift+← and Shift+→ |
| Play or pause | Shift+↓ | Shift+↓ |

## Pine Studio editor

| Action | macOS | Windows and Linux |
|---|---|---|
| New script | ⌘N | Ctrl+N |
| Show or hide the script list | ⌃⌘S | Ctrl+B |
| Show or hide the preview chart | ⌥⌘P | Ctrl+Shift+P |
| Find | ⌘F | Ctrl+F |
| Find next, find previous | ⌘G, ⇧⌘G | F3 or Ctrl+G, Shift+F3 |
| Comment or uncomment | ⌘/ | Ctrl+/ |
| Move line up or down | ⌥↑ and ⌥↓ | Alt+↑ and Alt+↓ |
| Duplicate line up or down | ⌥⇧↑ and ⌥⇧↓ | Alt+Shift+↑ and Alt+Shift+↓ |
| Show suggestions | ⌃Space or ⌥Esc | Ctrl+Space |
| Go to definition | ⌃⌘J or F12 | F12 |
| Rename a name everywhere | ⌃⌘E or F2 | F2 |
| Select next match | ⌘D | Ctrl+D |
| Select all matches | ⌥F3 or ⌃⌘G | Alt+F3 |
| Add cursor above, below | ⌃⇧↑ and ⌃⇧↓ | Ctrl+Alt+↑ and Ctrl+Alt+↓ |
