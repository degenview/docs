# Settings

Everything configurable lives in the Settings screen. Here's a tour of its sections.

## API Keys

- **Alpaca** — keys for US stock data. Stored in Keychain on macOS, or in environment
  variables elsewhere. See [Data sources](/markets/data-sources).
- **CoinMarketCap** — optional. Not required; adding a key can raise rate limits.

## Appearance

Choose Dark (default), Light, or System theme. See [Appearance](/workspace/appearance).

## MCP Server

Turn the local MCP server on or off, generate and manage tokens, and set client permissions.
See [MCP server](/mcp).

## Webhooks

Configure webhook delivery for price alerts. See [Delivery & background](/alerts/delivery).

## Storage

DegenView keeps your data — scripts, portfolios, alerts, and layout — on your device. Storage
settings let you see and manage where that data lives.
