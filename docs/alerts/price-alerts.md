# Price alerts

Price alerts notify you when a symbol crosses a level you choose. They are evaluated
**locally** — no account, no remote service.

## Conditions

An alert triggers when price crosses:

- **above** a level, or
- **below** a level.

## Levels

Set the level as either:

- an **absolute** price, or
- a **percentage** change.

## Frequency

Each alert is either:

- **once** — fires the first time the condition is met, then stops.
- **repeating** — fires again each time the condition is met.

## Delivery

Where an alert goes is configurable per alert — an in-app banner, a desktop notification on
macOS, or both. See [Delivery & background](/alerts/delivery).

## Managing alerts

Create, pause, and edit alerts from the [Alerts center](/alerts/alerts-center).
