# Tabs, windows & layouts

## Tabs and windows (macOS)

On macOS, DegenView uses native tabs and windows. Each tab is an independent workspace with
its own charts, timeframe, layout, zoom, and drawing state. You can:

- drag tabs to reorder them
- drag a tab out to detach it into its own window
- drag tabs together to merge them

## Windows and Linux

On Windows and Linux, DegenView runs as a single workspace window.

## Restored sessions

Your tabs, their order, and their window grouping come back when you relaunch. Close DegenView
and reopen it, and you're back where you left off.

## Layouts

Arrange charts as:

- **Vertical stacks** — charts stacked top to bottom.
- **Multi-column grids** — charts in columns.

Drag charts to reorder them, or drop them into a new column.
