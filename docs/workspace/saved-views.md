# Saved views & favorites

## Saved views

A **saved view** captures a whole chart setup in one named snapshot:

- the ticker set
- timeframe
- arrangement and zoom
- data source
- indicators
- appearance

Save a view once, then reopen it any time to get back to that exact layout. This is useful
for setups you return to regularly, like a "daily check" screen or a specific market to watch.

## Favorites sidebar

The Favorites sidebar is an app-wide, reorderable watchlist. Add a symbol to Favorites and it
stays one click away from anywhere in the app.

- **App-wide** — favorites are shared across tabs and windows.
- **Reorderable** — drag to put your most-watched symbols on top.

## The difference

- **Favorites** = a quick list of symbols, available everywhere.
- **Saved views** = full snapshots of a chart arrangement, reopened on demand.
