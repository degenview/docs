# Historical replay

Replay steps through the market candle by candle, starting from a historical point in the
past. Because only bars up to the current replay point are shown, there's **no lookahead** —
you see exactly what you would have seen at that moment.

## Controls

- **Play / pause** — advance the market or hold it.
- **Timeline scrubber** — jump to any point in the range.
- **Speed** — how fast bars advance.
- **Interval** — the step size between bars.

## Shared clock

The replay clock is shared across every chart in a tab, so all charts move together through
the same historical window.

## Why use it

Replay is a practice tool. Combine it with [Paper trading](/paper-trading) to test decisions
on historical data with no risk.
