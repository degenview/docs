# Portfolio

The Portfolio feature tracks what you hold and how it's performing. You can keep **multiple
portfolios**, each with its own transaction ledger and its own analytics.

## Why multiple portfolios?

Separate portfolios let you keep strategies or accounts apart — for example, a long-term
holdings portfolio and a short-term trading portfolio — each with its own cost basis and
profit picture.

## What a portfolio tracks

Every portfolio maintains:

- A **transaction ledger** — the trades you've recorded, using weighted-average accounting.
- **Live analytics** — see [Analytics & currency](/portfolio/analytics).

## Getting started

1. Create a portfolio.
2. Record your first transaction (see [Transactions](/portfolio/transactions)).
3. Open the portfolio overview to see value, allocation, and performance.
