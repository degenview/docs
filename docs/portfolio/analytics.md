# Analytics & currency

## Live analytics

Each portfolio shows, at a glance:

- **Value** — total current value.
- **Allocation** — how value is spread across assets.
- **24-hour movement** — how the portfolio moved in the last day.
- **Cost basis** — what you paid.
- **Realized P&L** — profit or loss already locked in by sells.
- **Unrealized P&L** — profit or loss on open positions.
- **Best and worst performers** — the assets leading and lagging.

## Portfolio history

DegenView keeps transaction-aware value snapshots, so you can see how a portfolio's value
changed over time. Choose a range from 1 day up to all time.

## Multi-currency reporting

Report portfolio values in any of these currencies:

- USD
- EUR
- GBP
- JPY
- CHF
- BTC

FX conversion is cached, so switching currencies is fast.

## Import and export

- **CSV import** — bring in existing transactions, including CoinMarketCap transaction
  exports with automatic asset mapping.
- **CSV export** — export your ledger for record keeping or use in other tools.

Importing is a good way to bootstrap a portfolio you already track elsewhere.
